# Касса школьного класса — отчёт для родителей

Статическая страница, которую видят родители. Публикуется через GitHub Pages.
Репозиторий не привязан к номеру класса: в 3В, 4В и дальше используется он же,
меняется только содержимое `index.html`.

## Что здесь лежит

- `index.html` — текущий отчёт: вёрстка, скрипты и данные в одном файле.
  Имя менять нельзя, Pages ищет именно `index.html`.
- `archive/` — отчёты прошлых учебных лет, по файлу на год (`2026-2027.html` и так далее).
- `robots.txt` и `<meta name="robots" content="noindex">` внутри страницы — запрет индексации.
  Страница доступна только по прямой ссылке.
- `.nojekyll` — отключает обработку Jekyll, чтобы GitHub отдавал файлы как есть.

## Откуда берутся данные

Страницу собирает ассистент из журнала кассы за текущий учебный год:
`Google Drive / For_sorting / Школа / Класс_Артура / <учебный год> / Свод / Касса_*.xlsx`.

Руками `index.html` не правят — следующая пересборка затрёт правки.
Чтобы поменять цифры, меняют журнал, а не страницу.

## Как обновить сайт

```bash
git add -A
git commit -m "отчёт на <дата>"
git push
```

Через минуту страница по ссылке обновится сама. Ссылка не меняется никогда.

## Смена учебного года

1. Скопировать текущий `index.html` в `archive/<год>.html`.
2. Положить на его место отчёт нового года.
3. Закоммитить и запушить. Ссылка в родительском чате остаётся прежней.

## Настройка Pages (один раз)

Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
